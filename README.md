# Champions du CP 🏆

Petite application d'apprentissage **hors-ligne** pour un enfant entrant au CP
(programme des 4 premiers mois), façon *Lingokids*, sur un thème sportif.

- 🏀 **Basket → Maths** : compter jusqu'à 20, comparer, suite des nombres, additions, compléments à 10, doubles, formes géométriques.
- 🎾 **Tennis → Lecture** : voyelles, lettres, syllabes (consonne + voyelle), compter les syllabes, lire des mots simples.
- ⚽ **Foot → Écriture** : tracer les chiffres et les lettres au doigt, reconnaître les lettres, majuscule/minuscule, lettre manquante.

Gamification : coupes à collectionner, étoiles, médailles, mascotte « Léo le lion »,
confettis et animations à chaque bonne réponse. Une **voix française** lit les consignes
(l'enfant n'a pas encore besoin de savoir lire).

## Utilisation immédiate (sans installation)
Ouvrir `index.html` dans un navigateur (Chrome sur Android de préférence).
Tout fonctionne hors-ligne, y compris la voix et la sauvegarde des coupes.

## Installer comme une vraie appli sur Android
1. Publier le dossier sur **GitHub Pages** (ou tout hébergement statique).
2. Ouvrir l'adresse dans **Chrome**.
3. Menu ⋮ → **Ajouter à l'écran d'accueil**.
   L'icône trophée apparaît ; l'appli se lance en plein écran et marche sans connexion.

## Publier sur GitHub Pages
1. Créer un dépôt et y déposer **tout le contenu de ce dossier**
   (`index.html`, `manifest.json`, `sw.js`, `icons/`).
2. Dépôt → *Settings* → *Pages* → *Branch: main* → *Save*.
3. Ouvrir l'URL fournie ; le service worker met tout en cache pour l'usage hors-ligne.

## Espace parents
Accessible depuis l'accueil : activer/couper la voix et les sons, changer le prénom,
ou tout réinitialiser.

Fait avec ❤️ — bon entraînement, champion !
